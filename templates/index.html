How PlumeEst works

PlumeEst implements the Gaussian plume dispersion model, the industry-standard method used by environmental agencies (US EPA, CPCB) for estimating steady-state atmospheric pollutant concentrations downwind of a continuous point source. The full source code is open and available on GitHub.

1. Ground-level concentration
$$C(x,y,0) = \frac{Q}{\pi \, u \, \sigma_y \, \sigma_z} \exp\!\left(-\frac{y^2}{2\sigma_y^2}\right) \exp\!\left(-\frac{H^2}{2\sigma_z^2}\right)$$
$C$ground-level concentration (µg/m³)
$Q$emission rate (g/s)
$u$mean wind speed at stack height (m/s)
$\sigma_y, \sigma_z$horizontal and vertical dispersion coefficients (m)
$H$effective stack height = physical height + plume rise (m)
$x, y$downwind and crosswind distances from source (m)
2. Pasquill-Gifford dispersion coefficients (Briggs rural)
$$\sigma_y(x) = a \, x \left(1 + b \, x\right)^{-1/2}$$ $$\sigma_z(x) = c \, x^d$$
$a, b$horizontal spread coefficients — depend on stability class
$c, d$vertical spread coefficients — depend on stability class
3. Briggs plume rise
$$F = g \, v_s \, r^2 \, \frac{T_s - T_a}{T_s}$$ $$\Delta H = \frac{1.6 \, F^{1/3} \, x_f^{2/3}}{u}$$
$F$buoyancy flux parameter (m⁴/s³)
$v_s$stack exit velocity (m/s)
$r$stack radius (m)
$T_s, T_a$stack gas and ambient temperature (K)
$x_f$distance to final plume rise (m)
$\Delta H$plume rise above stack (m)
